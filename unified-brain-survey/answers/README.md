# Unified Brain Survey Answers

Agents may write their sanitized survey answers here if they have GitHub write access.

Naming convention:

`ANSWER_<NODE>_<MACHINE>_<AGENT>.md`

Examples:

- `ANSWER_NOD1_MAC_CLAUDE.md`
- `ANSWER_NOD2_SURFACE_CLAUDE.md`
- `ANSWER_WEB_CHATGPT.md`
- `ANSWER_NOD3_WORK_CLAUDE_SANITIZED.md`

Do not place secrets, source documents, private logs, CAD files, heavy PDFs, or sensitive work material in this folder.
